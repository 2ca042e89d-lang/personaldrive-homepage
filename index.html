PersonalDrive Sync

Personal Google Drive synchronization application for Linux Mint.

Description

This application allows you to mount and sync your Google Drive data locally on your computer for personal backup and synchronization.

Features

  • Mount Google Drive as local folder
  • Automatic synchronization
  • Works offline with local cache
  • Personal use only
